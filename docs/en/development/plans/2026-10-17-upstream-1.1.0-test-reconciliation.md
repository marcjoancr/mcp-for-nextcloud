# Upstream 1.1.0 test reconciliation

This closes the expanded-case accounting required by P0/P9 of the
[integration plan](2026-10-17-upstream-1.1.0-capability-integration.md).
The [machine-readable ledger](../contracts/upstream-1.1.0-test-reconciliation.json)
records the exact source pins, source/target class, every expanded method including
data-provider suffixes, final paths, explicit supersessions and inventory hashes.
The [source inventory](2026-10-17-upstream-1.1.0-inventory.md) allocates all 393
changed paths. The [execution report](2026-10-17-upstream-1.1.0-integration-report.md)
is the authority for actual green runs, candidate hashes and remaining gates.

## PHP accounting

- Upstream `0911f9123a661968e707fc4c391adcf9d37c3e84`: 7,433 expanded cases.
- Local baseline `1f0b4232e18b2c778d3585b878116d1cabb93d05`: 5,280 expanded cases.
- Total source identities: **12,713**, including overlapping regressions.
- Final ordinary suite: **7,657** expanded cases. Native cases remain in the
  separate Integration configuration; each matrix cell collects 200 cases.
- **12,663** source identities retain the same expanded method/dataset in a final
  owner; **50** have an explicit superseding case or behavioral suite and reason.
  No identity is unallocated. This arithmetic is traceability, not proof that
  names alone preserve semantics: final contract assertions and executed gates
  supply that evidence.

The ledger groups exact expanded names by source/target class to avoid repeating
namespace prefixes thousands of times. Its `superseded` entries explain removed
source-snippet UI assumptions, constructor fallbacks, API dependencies and approved
contract changes. Direct OCP Server lookup and IIsAdminBackend dependencies are
absent from production; their source-derived API cases are retired. Required
IUserConfig starts at the declared Nextcloud 32 minimum. No fake API alias or
optional dependency fallback was added to retain obsolete tests.

Approved deltas include generic missing-resource responses for excluded nodes,
component-qualified DAV lookups and generation-qualified OAuth revocation.
Account deletion is processed through the native cause listener and deferred
cleanup; account disable still performs its user cut. Local regressions for expired
spent-token history, resource byte equality and transient tag failures remain
executable. Newly ported original cases cover legacy credential migration, every
Calendar tool's ATTACH output, group-count boundaries and credential liveness.

## Browser accounting

The immutable upstream export executed all **209** unique Node frontend scenarios
successfully. Each source file/title is allocated to final behavioral suites in the
ledger. These are many-to-many allocations: a composed-page scenario can exercise
several former VM/source-slicing cases, while data-driven planner cases expand
independently. The final inventory names **203** unique Playwright scenarios,
executed in Chromium, Firefox and WebKit (**609** engine cases, retries disabled).
Neither the retired VM runner nor upstream global scripts are runtime dependencies.

Historical eight/ten-section assertions are replaced by nine inline sections and
two drawers. Source offsets, global export ordering and generated-ID regexes are
superseded by real rendering, focus, navigation, revision, recovery and disposal
checks. Permanent live regions retain delayed accessible announcements while
reserving their layout immediately; deterministic pointer-down/timer/pointer-up
cases prevent confirmation buttons moving before the click completes. Theme token
constraints remain in AdminAssetsTest; real Nextcloud theme/CSP and assistive
technology review are separate gates.

The [exclusion/folder contract](../contracts/exclusion-and-folder-exposure.md)
replaces both historical upstream contract Markdown files with final owners and
explicit evidence limits. Historical private CI results are not claimed for this
candidate. Enumeration XML and original-run JUnit hashes are preserved in the
ledger; `--list` output is never treated as execution evidence.

The final independent review added two PHP regressions and nine browser scenarios
(27 engine cases). They reproduce the undated revocation race, post-commit logging
failure and cross-user scope continuation/detached-control errors. Their failing
and corrected runs are documented in the execution report. They add coverage;
none of the original source identities or its explicit supersessions was removed.
