the user to accept sponsorship/decision coordination **only if willing**, then name a competent
operator and recovery owner before allocating resources. This is not an assignment
to the user by default. One person may hold several roles if competent and explicitly
accepting each responsibility; use a separate technical reviewer where available.
Automated assistance can prepare evidence but cannot replace these owners.
